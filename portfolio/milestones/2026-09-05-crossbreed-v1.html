03 — Regulated healthcare SaaS

Optum — StepWise PLM

Client Optum · Agency TEKsystems
Role Senior UX Designer · StepWise

The problem

The people using it — actuaries, underwriters, compliance, product — think in spreadsheets. What the tool produces is a website, where brokers and employers work out what each employee actually pays for coverage.

What I did

Kept the spreadsheet. Fighting a fluent mental model was never going to work. Instead I put the output beside the input — the broker-facing site renders live next to the grid, so every cell edit has a visible consequence.

Edit the grid, watch the site change Input and output on one screen

How I work

Three things

Systems, not screens

I design systems that happen to produce pages. The best outcome is usually that the "after" isn't prettier — it's the same, everywhere, for the first time.

Craft survives handoff

A design that can't survive engineering isn't finished. Figma deeply — auto layout, variants, tokens — then HTML, CSS and React to carry it through. This page is the demonstration.

Evidence over opinion

Usability testing, journey mapping, analytics. I let the numbers argue with my first draft, and I measure what matters: task success, satisfaction, handoff speed.
